## 1.1 编写选择问题程序并测试不同 N 的运行时间

**题目要点**：求第 k 大的元素（k = N/2），实现至少两种算法并画出运行时间表。

三种算法（代码：`ch02_algorithm_analysis/kth_largest.c`；计时程序：`demos/selection_timing.c`）：

| 算法 | 时间 | 额外空间 | 破坏输入 |
|------|------|----------|----------|
| 排序后取第 k 个 | O(N log N)（插入排序版是 O(N²)） | O(1)（qsort 版 O(N)） | 是 |
| 大小为 k 的最小堆 | O(N log k)，k = N/2 时是 O(N log N) | O(k) | 否 |
| 快速选择 | 平均 O(N)，最坏 O(N²) | O(1) | 是 |

**运行时间表的形态**（自己跑 `make demos && ./build/selection_timing` 可得到本机真实数据）：

- N 每翻 4 倍：排序法约涨 4×log 的倍数（≈ 5 倍），堆法同理，快速选择约涨 4 倍；
- 常数上：qsort 最快（缓存友好、无额外分配）；快速选择的常数也不小但**渐近更优**；
- 关键结论：**quickselect 的 O(N) 才是渐近最优**（下界 Ω(N)，因为必须至少读一遍输入），
  但它的 O(N²) 最坏情况要靠「三数取中 / 随机化枢轴」压住。

`demos/selection_timing.c` 会同时校验三种方法结果一致，并打印毫秒表。

## 1.2 编写字谜游戏求解程序

**题目要点**：在 R×C 字母网格中找出单词表里所有出现的单词（8 个方向，含反向）。

**解法**（代码：`ch01_introduction/word_puzzle.c`）：
对每个单词 w（长度 L），枚举每个起点 (r,c) 与 8 个方向 `(dr,dc) ∈ {-1,0,1}²\{(0,0)}`，
逐字符比较。

- **时间** `O(W · R · C · L)`；**空间** O(1)（除存放输出）；
- 方向向量只为 8 个，所以反向单词不需要单独处理——反向就是 dr、dc 取负后的另一个方向。

**测试覆盖**：横向 `abcd`、纵向 `aeim`、主对角线 `afkp`、反对角线 `dgjm`、
需要反向才命中的 `mj`、以及不存在的 `nope`（必须 0 命中）。

**两个实现细节**：
1. 长度为 1 的单词在 8 个方向上等价，若不去重同一格会被记 8 次；
   实现里对单字符单词只检查一个方向。
2. 优化（若 W 很大）：把单词表按首字母分桶，只从匹配首字母的格子出发；
   或反过来——从每个格子沿 8 个方向生成长度 ≤ Lmax 的串，放入哈希表/字典树匹配，
   可把每格代价降到与 L 无关（平均）。

## 1.3 只用 PrintDigit 输出任意实数

**题目要点**：只允许使用 `PrintDigit(d)`（输出单个数字字符 0~9），打印任意实数。

**核心洞察：递归天然实现「先高位后低位」**。
要把整数倒过来输出（低位先算出来、高位先输出），不需要数组或字符串，
只要「先递归处理 n/10，再输出 n%10」：

```
PrintOut(N):   if (N >= 10) PrintOut(N / 10);   PrintDigit(N % 10);
```

**实数**：整数部分用 `PrintOut`，小数点用 `fputc`（小数点不是数字，不属于 PrintDigit 的职责），
小数部分反复「乘 10、取出整数位、减去该位」：

```
frac = x - floor(x);
repeat decimals 次:  frac *= 10;  d = (int)frac;  PrintDigit(d);  frac -= d;
```

**实现**（`ch01_introduction/print_real.c`）与**边界**：
- `print_real_to(FILE*, x, decimals)` 便于测试（用 `tmpfile()` 读回输出比对）；
- 负数先输出 `'-'` 再取绝对值；
- 这是**截断**而非四舍五入（要四舍五入就先加 `5·10^-(decimals+1)`）；
- `decimals == 0` 时仍会输出一个小数点（"42."），这是刻意保留的行为，测试里断言了它；
- 同一个原语可以做**任意进制**输出（2~10，`print_base_to`）：`255` → 二进制 `11111111`、
  八进制 `377`。若扩展到 16 进制，需要给 `PrintDigit` 增加字母分支。

## 1.4 实现支持嵌套 #include 的文件展开程序

**题目要点**：读入一个文件，把其中的 `#include "..."` 递归展开后输出。

**实现**（`ch01_introduction/include_expand.c`）要点：

1. **识别指令**：跳过前导空白，要求 `#`、若干空白、`include`、若干空白、`"路径"`。
   只支持 `"..."` 形式（`<...>` 属于系统头文件，玩具实现不处理）；
2. **相对路径解析**：`#include` 的路径相对于**包含它的那个文件**所在目录，而不是当前工作目录。
   所以要把「父文件所在目录」与包含名拼接（用 `strrchr(path,'/')` 取目录前缀）；
3. **循环包含检测**：维护一个**包含栈**（所有正在展开的文件路径）。
   若待展开的文件已在栈中，说明 `a.h → b.h → a.h`，立即报错而不是无限递归；
4. **深度限制**：`max_depth` 再兜一层底（教材的展开程序与真实预处理器都有类似限制）；
5. 被包含文件的行数要计入返回值，便于调用方核对。

**测试**（`tests/fixtures/`）：
- `inc_a.h → inc_b.h → inc_c.h` 展开结果逐字符比对，行数 = 6；
- `cycle_x.h ↔ cycle_y.h` 必须报 `circular include`；
- `inc_d1 → d2 → d3` 在 `max_depth = 2` 时必须报深度超限；
- 文件不存在时报 `cannot open`。

> 与真实预处理器的差距：不处理宏展开、条件编译、头文件保护、`#include <...>`、
> `#pragma once`、以及「同一头文件被包含两次只展开一次」的规则（真实 C 靠
> include guard 宏来实现最后一点）。

## 1.5 证明对数不等式与恒等式

**(a) log₂(XY) = log₂X + log₂Y**
令 A = log₂X、B = log₂Y，则 X = 2^A、Y = 2^B。
由幂运算律 `2^A · 2^B = 2^(A+B)` 得 XY = 2^(A+B)，
两边取 log₂ 即得 `log₂(XY) = A + B`。∎

**(b) log₂(X^B) = B·log₂X**
对整数 B ≥ 1 由 (a) 归纳（B = 1 显然；B = k+1 时 X^(k+1) = X^k · X）；
B = 0 时两边为 0；B < 0 由 1/X 的情形得到。

**(c) log₂X < X 对所有 X > 0 成立**
令 X = 2^Y（Y 为实数），等价于证 `Y < 2^Y`：
- Y ≤ 0 时右边 ≥ 1 > Y 显然；
- Y > 0 时对 ⌈Y⌉ 用归纳：2^0 = 1 > 0，且 2^(n+1) = 2·2^n > 2n ≥ n+1（n ≥ 1），故 2^Y ≥ 2^⌊Y⌋ > Y。∎

**常用推论（本章与后面各章反复使用）**：

| 恒等式 | 用法 |
|--------|------|
| `log₂(N²) = 2 log₂N` | 化简 `N log(N²)` 与 `N log N` 同阶 |
| `log₂(2^N) = N` | 指数与对数互逆 |
| `log₂(1/X) = −log₂X` | 换底公式 `log_a X = log_b X / log_b a` |
| `⌊log₂N⌋ + 1` = N 的二进制位数 | 「反复折半需要多少步」 |
| `2^N > N^2 (N ≥ 5)` | 指数最终压倒多项式，可用归纳证明 |

## 1.6 求若干无穷级数的和

| 级数 | 和 | 推导 |
|------|----|------|
| Σ_{i≥1} 1/2^i | **1** | 首项 1/2、公比 1/2 的等比级数：`a/(1−r) = (1/2)/(1/2)` |
| Σ_{i≥0} 1/2^i | **2** | 上式再加 i=0 的 1 |
| Σ_{i≥1} 1/4^i | **1/3** | `(1/4)/(1−1/4) = 1/3` |
| Σ_{i≥1} 1/k^i (k>1) | **1/(k−1)** | 等比级数通式 |
| Σ_{i≥1} i/2^i | **2** | 由 Σ_{i≥0} x^i = 1/(1−x) 求导得 Σ i x^(i−1) = 1/(1−x)²，取 x = 1/2 |
| Σ_{i≥1} 1/(i(i+1)) | **1** | 裂项 `1/i − 1/(i+1)`，部分和 = 1 − 1/(N+1) → 1 |
| Σ_{i≥0} i/2^(i+1) | **1/2** | 上一行乘 1/2（第 1 章推导「平均递归代价」时会用到） |

数值核对：这些恒等式在 `tests/test_ch01.c` 里对前若干项做了部分和验证
（第 1.6 题本身是书面题，数值验证只是为了说明收敛趋势）。

## 1.7 估计调和级数部分和

H_N = Σ_{i=1}^{N} 1/i。**证明 H_N = Θ(log N)**：

**下界**（积分比较）：对 i ≥ 1 有 `1/i > ∫_i^{i+1} dx/x`（因为被积函数在 [i, i+1] 上递减，
左端点为最大值），求和得
`H_N > ∫_1^{N+1} dx/x = ln(N+1) > ln N`。

**上界**：对 i ≥ 2 有 `1/i < ∫_{i-1}^{i} dx/x`，故
`H_N < 1 + ∫_1^{N} dx/x = 1 + ln N`。

于是 `ln N < H_N < ln N + 1`，即 H_N = Θ(log N)（换底只差常数，log₂ 与 ln 同阶）。

**更精确的展开**：`H_N = ln N + γ + 1/(2N) − 1/(12N²) + O(1/N⁴)`，
其中 γ ≈ 0.5772156649 是欧拉–马歇罗尼常数。

**初等分组证明**（考试常写这个）：
`1/2`；`1/3 + 1/4 ≤ 1/2 + 1/2 = 1`；`1/5+…+1/8 ≤ 4·(1/4) = 1`；……
每组的项数是上一组的两倍、每项不超过组内最大项，故每组和 ≤ 1，
分组数为 ⌊log₂N⌋，得到 `H_N ≤ 1 + ⌊log₂N⌋`。

**用途**：H_N 出现在「拒绝采样生成随机置换的期望抽取次数」（第 2 章 2.7）、
「并查集按大小合并的均摊分析」等处。

## 1.8 计算 2^100 mod 5

**答案：1。**

**推导**：`2^4 = 16 ≡ 1 (mod 5)`，而 `100 = 4 × 25`，所以
`2^100 = (2^4)^25 ≡ 1^25 = 1 (mod 5)`。

**为什么这题值得出**：直接把 2^100 算出来是不可行的（超出任何定长整数类型），
必须使用**模运算性质 + 快速幂**（第 2 章 2.16）：`pow_mod(2, 100, 5)` 只需
⌊log₂100⌋ + popcount(100) = 6 + 3 = 9 次乘法，中间结果始终 < 25。
这也是 RSA 等密码学算法的基础手法。

## 1.9 证明斐波那契数列相关性质

约定 F₀ = 0, F₁ = 1, F_N = F_{N−1} + F_{N−2}。

**(a) Σ_{i=1}^{N} F_i = F_{N+2} − 1**
归纳：N = 1 时左边 = F₁ = 1，右边 = F₃ − 1 = 2 − 1 = 1 ✓。
归纳步：Σ_{i=1}^{N} F_i = (Σ_{i=1}^{N−1} F_i) + F_N = (F_{N+1} − 1) + F_N = F_{N+2} − 1 ✓。∎

**(b) Σ_{i=1}^{N} F_i² = F_N · F_{N+1}**
归纳：N = 1 时 1 = F₁F₂ = 1·1 ✓。
归纳步：`F_{N−1}F_N + F_N² = F_N(F_{N−1} + F_N) = F_N F_{N+1}` ✓。∎

**(c) 相邻两项互素：gcd(F_N, F_{N+1}) = 1**
用 `gcd(a,b) = gcd(a, b−a)`：`gcd(F_N, F_{N+1}) = gcd(F_N, F_{N+1} − F_N) = gcd(F_N, F_{N−1})`，
归纳下去到 `gcd(F₁, F₂) = gcd(1,1) = 1`。∎（测试里对 N ≤ 60 逐个验证。）

**(d) 与黄金比的关系**：F_N ≈ φ^N/√5，其中 φ = (1+√5)/2 ≈ 1.6180。
更精确地 `F_N = (φ^N − ψ^N)/√5`，ψ = (1−√5)/2 ≈ −0.618，
且 |ψ^N/√5| < 1/2，所以 F_N 就是 φ^N/√5 四舍五入的结果。
这条结论解释了为什么朴素递归求 F_N 是 **O(φ^N)** 的指数级算法（第 2 章）。

**(e) gcd(F_m, F_n) = F_gcd(m,n)**：这是 (c) 的推广，可用「F_{m+n} = F_{m−1}F_n + F_m F_{n+1}」
配合欧几里得算法证明——它说明**斐波那契数是欧几里得算法的最坏输入**
（第 2 章 2.x 中「gcd 的 O(log N) 上界是紧的」这一结论的来源）。

## 1.10 证明奇数和与立方和公式

**(a) 前 N 个奇数之和 = N²**
归纳：N = 1 时 1 = 1² ✓。归纳步：
`(N−1)² + (2N−1) = N² − 2N + 1 + 2N − 1 = N²` ✓。∎

（另一种证明：`1+3+…+(2N−1) = 2(1+2+…+N) − N = N(N+1) − N = N²`。）

**(b) Σ_{i=1}^{N} i³ = (N(N+1)/2)² = (Σ i)²**
归纳：N = 1 时 1 = 1 ✓。归纳步：设 Σ_{i≤N−1} i³ = ((N−1)N/2)²，则

```
((N−1)N/2)² + N³ = N²[(N−1)²/4 + N] = N²(N² − 2N + 1 + 4N)/4
                 = N²(N+1)²/4 = (N(N+1)/2)²   ✓ ∎
```

**结论的意义**：立方和等于和的平方——偶发但真实；也说明
「Σ i³ 是 Θ(N⁴)」（因为 (N(N+1)/2)² ~ N⁴/4），这提醒我们
**求和记号里的次数要算清楚**，别把 Σ i³ 误当成 Θ(N³)。

两项公式在 `tests/test_ch01.c` 中对 N ≤ 200 逐项数值验证。
