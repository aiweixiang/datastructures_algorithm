## 2.7 函数增长率排序

把下列函数按增长率**从小到大**排列，并指出同阶者：
`N, √N, N^1.5, N^2, N log N, N log log N, N log^2 N, N log(N^2), 2/N, 2^N, 2^(N/2), 37, N^2 log N, N^3`

**答案**：

```
2/N  <  37  <  √N  <  N  <  N log log N  <  N log N ≈ N log(N²)  <  N log²N
     <  N^1.5  <  N²  <  N² log N  <  N³  <  2^(N/2)  <  2^N
```

**关键理由**：

- `N log(N²) = 2 N log N`，与 `N log N` **同阶**（常数因子 2 不计）；
- `N log log N < N log N < N log²N < N^1.5`：对足够大的 N 有 `log N < √N`，故 `N log²N < N·N^0.5 = N^1.5`；
- `N² log N` 与 `N²` **不同阶**（多了一个无界因子 log N），但都小于 `N³`；
- `2^(N/2) = (√2)^N`，与 `2^N` 同底数不同底，指数增长；`2^N` 更大；
- `2/N` 递减趋于 0，是最小的一档（比常数 37 还小）。

**结论性提醒**：渐近比较对「常数因子」不敏感，但对多出来的 **log 因子**敏感；
这就是 O(N²) 与 O(N² log N) 必须区分的理由。

## 2.x 最大子序列和（本章的样板例题）

四种算法，实现见 `max_subsequence_sum.c`：

| 函数 | 时间 | 做法 |
|------|------|------|
| `mss_cubic` | O(N³) | 枚举 i、j，再求和 |
| `mss_quadratic` | O(N²) | 枚举 i，j 递增时**复用**上一个求和结果 |
| `mss_divide_conquer` | O(N log N) | 分治 |
| `mss_linear` | O(N) | 在线算法：负前缀直接丢弃 |

**分治的递推式推导**：

```
T(1) = 1
T(N) = 2 T(N/2) + O(N)
```

每层有 N 次基本操作，递归树共 log N 层，故 `T(N) = O(N log N)`。

**线性算法的核心不变量**：若 `this_sum < 0` 则把它置 0——因为任何以该段负前缀结尾的
后续子序列，去掉这段前缀后只会更大，所以负前缀永远不可能属于最优解。

**教材样例**：`{-2, 11, -4, 13, -5, -2}` 的最大子序列为 `11 + (-4) + 13 = 20`，
对应下标区间 `[1, 3]`（`mss_linear_range` 会返回该区间；全负数时返回 −1/−1 表示空子序列）。

## 2.x 二分查找

实现在 `binary_search.c`：

- `bisect`：最坏情形比较次数为 `⌊log2 N⌋ + 1`（每轮区间至少缩小一半）；
- **中点写法**：`mid = low + (high − low) / 2`。写成 `(low + high) / 2` 在
  `low + high` 超过 int 上限时会溢出成负数，从而越界访问——这是本题最常见的错误答案；
- `lower_bound_idx` / `upper_bound_idx`：返回「第一个 ≥ x」/「第一个 > x」的下标
  （区间用 `[lo, hi)` 表示，答案可能为 N）。二者是 C++ `std::lower_bound/upper_bound` 的语义，
  在「统计 x 出现次数」时 `upper − lower` 即为重数；
- 递归版本 `bisect_recursive` 与迭代版本等价，但多了 O(log N) 的栈空间。

**几点结论**：
1. 二分查找要求**随机访问**（数组）；用在链表上会退化为 O(N)；
2. 输入必须有序——排序一次的 O(N log N) 只有在查询次数足够多时才划算
   （查询 Q 次时，两种方案代价分别为 O(N log N + Q log N) 与 O(QN)，Q > log N 时前者胜出）；
3. 存在 O(1) 的「插值查找」特例（均匀分布），但最坏情况仍是 O(N)。

## 2.x Euclid 算法与 gcd

实现见 `gcd.c`（`gcd_euclid`、`gcd_iterative`、`gcd_extended`、`lcm`）。

**O(log N) 的证明**：设 m > n。看一次迭代：`(m, n) → (n, m mod n)`。
- 若 `n ≤ m/2`，则新参数 `n ≤ m/2`，规模已减半；
- 若 `n > m/2`，则 `m mod n = m − n < m/2`，新参数的第二个分量 < m/2。

即**两次迭代之内**两个参数都会被压到原来的 m/2 以下，因此迭代次数 ≤ 2 log2 m = O(log N)。

**扩展 Euclid**：`gcd_extended(a,b,&x,&y)` 返回 g 并给出满足 `a·x + b·y = g` 的一组解，
是求模逆元（`a·x ≡ 1 (mod m)` 当 gcd(a,m)=1）的基础。测试中用 `m*x + n*y == gcd(m,n)` 全量校验。

`lcm(m,n) = m / gcd(m,n) * n`：**先除后乘**，避免中间结果溢出。

## 2.x 幂运算 x^N

实现见 `power.c`。

- `pow_slow`：N 次乘法，O(N)；
- `pow_fast`：反复平方，O(log N)。递推式 `T(N) = T(⌊N/2⌋) + 2`，解得 `T(N) = O(log N)`；
  迭代写法按 N 的二进制位处理：位为 1 就乘进结果，每轮把 x 平方、N 右移一位；
- `pow_mod(x, n, mod)`：每步取模，中间结果不超过 `mod²`，是 RSA 等算法的基础，
  同时避免了大数溢出。

**易错点**：`x *= x` 在最后一轮仍然执行，虽然不影响正确性，但在有溢出风险的场景
（如未取模的大指数）应改为「只在还需要时平方」。

## 2.x 对数与 2 的幂

实现见 `log2_floor.c`。

- `⌊log2 N⌋` 的两种写法：乘法/除法循环（模拟）与**移位**写法（`while (v >>= 1) ++k;`）。
  后者揭示了对数的本质：**反复折半的次数就是二进制位数减一**；
- `⌈log2 N⌉`（用于「至少多少位/多少次才能表示 N 种情况」）：`N ≤ 1` 时为 0，否则 `⌊log2(N−1)⌋ + 1`；
- `is_power_of_two(n)`：`n > 0 && (n & (n−1)) == 0`。这条位运算恒等式是很多
  「2 的幂」类判断、以及扩容循环（`for (i = 1; i < N; i *= 2)`）习题的快捷解；
- 注意 `n ≤ 0` 时 `log2` 无定义，实现统一返回 −1（并作为前置条件写进注释）。

## 2.x Horner 法则

实现在 `horner.c`。求 `a_n x^n + … + a_1 x + a_0`：

- 朴素写法对第 i 项重新求 `x^i`，总乘法次数 `Θ(N²)`；
- Horner 法则：`((…(a_n·x + a_{n−1})·x + a_{n−2})·x + …)·x + a_0`，**N 次乘法 + N 次加法**，O(N)。

测试用随机系数对拍 Horner 与朴素求值（容差 1e-6），并固定验证 `1+2x+3x²` 在 x=2 时为 17。

## 2.x Fibonacci：坏递归与好算法

实现见 `fibonacci.c`。

| 函数 | 时间 | 说明 |
|------|------|------|
| `fib_recursive` | O(φ^N)，φ=(1+√5)/2 ≈ 1.618 | 存在指数级的重复计算 |
| `fib_iterative` | O(N) | 只保留最近两项，O(1) 空间 |
| `fib_memo` | O(N) | 记忆化递归（测试中与迭代版逐项对拍） |
| `fib_matrix` | O(log N) | 2×2 矩阵快速幂 |

**递归树分析**：`T(N) = T(N−1) + T(N−2) + O(1)`，与 Fibonacci 自身同阶，
故 `T(N) = O(φ^N)`。以 N=45 为例，朴素递归约 10^9 次调用，而迭代版 45 次循环——
这就是「合成效益法则」的反面教材。

**矩阵快速幂**：
```
[1 1]^n   [F(n+1) F(n)  ]
[1 0]   = [F(n)   F(n-1)]
```
用二进制幂（同 `pow_fast`）在 O(log N) 内算出。注意 64 位无符号整数最大只能表示到
`F(93) = 12200160415121876738`，测试中以此为边界。
