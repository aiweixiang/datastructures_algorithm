## 二、证明与推导

### 4.1 ~ 4.3　二叉树的基本性质

设结点数为 n、边数为 e、度为 2 的结点数为 n₂、叶结点数为 n₀。

* **n = e + 1**：除根外每个结点恰有一条来自父亲的边。
* **叶结点与二度结点的关系**：所有结点的度之和 = e，即
  `n₁ + 2n₂ = n − 1`；又 `n = n₀ + n₁ + n₂`，两式相减得
  `n₀ = n₂ + 1`。
* **深度**：空树取 −1，`depth = max(depth_L, depth_R) + 1`（代码即此式）。

### 4.9　由遍历序列重建二叉树

* 已知**中序 + 前序**：前序首元素是根，在中序里把序列切成左右两段，
  递归即可；**中序 + 后序**同理（后序末元素是根）。
* 只知道**前序 + 后序不能唯一确定**：反例 —— 两棵深度 2 的树，
  一个根只有左孩子、一个根只有右孩子，前序都是 `A B`、后序都是 `B A`。

### 4.14　内部路径长（IPL）

`IPL = Σ(depth(v))`，根深度取 0。递推：

```
IPL(空) = 0
IPL(T)  = IPL(L) + IPL(R) + size(L) + size(R)
```

若用 `size(v)` 域，可在一次自底向上的遍历里同时算出。

**理想平衡树**（n = 2^{h+1}−1，第 d 层有 2^d 个结点）的闭式：

```
IPL = Σ_{d=0}^{h} d·2^d = (h−1)·2^{h+1} + 2
```

h = 5 时 = 4·64 + 2 = **258**，测试直接核对该值。

### 4.15　AVL 树的最少结点数

高度 h 的 AVL 树，为了让结点最少，左右子树高度只能取 h−1 和 h−2，
且都要取各自的最少结点数：

```
N(0) = 1,  N(1) = 2,
N(h) = N(h−1) + N(h−2) + 1        (h ≥ 2)
```

解得 `N(h) = F(h+3) − 1`（F 为 Fibonacci，F(1)=F(2)=1）。
前几项：**1, 2, 4, 7, 12, 20, 33, 54**（测试逐项核对）。
渐近 `N(h) ≈ φ^{h+3}/√5 − 1 ≈ 1.894^h`。

### 4.16　四种失衡与旋转

设失衡结点 X，插入发生在：

| 形态 | 条件 | 修复 |
|------|------|------|
| LL | 左孩子的左子树 | 单旋（右旋） |
| RR | 右孩子的右子树 | 单旋（左旋） |
| LR | 左孩子的右子树 | 双旋（先左旋再右旋） |
| RL | 右孩子的左子树 | 双旋（先右旋再左旋） |

旋转只改 3 个指针，`O(1)`；插入沿途最多一次旋转（或双旋）即恢复平衡，
所以**插入是 O(log N)**。

### 4.17　完全平衡

插入 1..2^k−1 时，中位数每次落在正中，左右子树结点数相等，
故每个结点左右子树高度相同 —— 即从空树开始按中序顺序插入，
得到的是一棵**满树**（高度 k−1、无单孩子结点）。

### 4.21　高度域位宽

AVL 树高 h 与结点数 n 的关系由 4.15 给出，反解即
`h ≤ 1.44·log₂(n+2) − 0.33...`。要存 0..h 的整数需要
`ceil(log₂(h+1))` 位。测试取 n = 10⁶：

```
h ≈ 1.44·log₂(10⁶) ≈ 28.7 → h_max = 28 → ceil(log₂ 29) = 5 位
```

故**一个字节（8 位）绰绰有余**；`avl_height_bits(10⁶) ≤ 8` 通过。
代码里 `avl_height_bits` 用 `avl_min_nodes(h+1) ≤ n` 求 h，再数位数。

### 4.22　AVL 高度上界

由 `N(h) ≥ φ^{h+3}/√5 − 1` 且 `N(h) ≤ n`：

```
h ≤ 1.44·log₂(n+2) − 0.33
```

即 AVL 树高度是**对数级**，且常数比随机 BST 的 1.39 略大，值得。

### 4.25 ~ 4.27　伸展树

* **4.25**：按 1..n 递增插入（每次把新最大元伸展到根），最终是一条
  **左链**，访问最小值要沿左链走 n 步 —— 单次操作最坏 `Θ(N)`。
  注意递减插入得到的是**右链**，此时左链长度是 1（测试最初就栽在这个方向弄反上）。
* **4.26**：Tarjan 的“顺序访问定理”：在一棵由任意插入构造的伸展树上，
  按 1,2,…,n 顺序访问的总旋转数是 `O(N)`（而非 `O(N log N)`）。
  测试对 n = 32,128,512 断言总旋转数 `≤ 8n`。
* **4.27**：任意单次操作最坏 `Θ(N)`，但**摊还** `O(log N)`；
  测试统计大量随机访问的平均旋转次数并断言其上界。

### 4.38　B* 树

B* 树把结点**最小填充度**从 ⌈M/2⌉−1 提到约 ⌊2M/3⌋：

* 兄弟结点都满时才分裂，且**不**把中位键上推、各分一半，
  而是把一个结点的键“挪”给未满的兄弟（顺序仍保持）；
* 两个兄弟都满时才把它们与父亲的分隔键一起分成**三个**结点，
  每个约 2M/3 满，因此树更矮、空间利用率更高（≥ 2/3）。

代价是删除/插入的再平衡更复杂。本仓库用 `btree_check` 校验
叶子同深度、关键字上下界、孩子数 = 关键字数 + 1、区间有序这四条不变量，
B 树的插入/删除已在 200k 次随机操作下与有序集合模型逐操作对拍。

### 4.41 / 4.42 / 4.43

* **相似**：`相似(a,b) = 空/空 → true；一空一非空 → false；
  否则 相似(a_L,b_L) ∧ 相似(a_R,b_R)`。左右**不允许**交换。
* **同构**：在相似的基础上允许交换左右，
  `(相似(L,L) ∧ 相似(R,R)) ∨ (相似(L,R) ∧ 相似(R,L))`。
* **BST 判定**：只比较「父 > 左孩子、父 < 右孩子」是**错的**
  （反例：把 10 放到 5 的左子树的右孩子处）。正确做法是带
  **开区间 (lo, hi)** 递归：`lo < key < hi`，递归时把区间收紧。

### 4.44　FindKth

若每个结点维护子树大小 `sz`，则从根出发：

```
if k ≤ sz(left)        走向左孩子
else if k == sz(left)+1  返回当前结点
else k -= sz(left)+1    走向右孩子
```

单次 `O(树高)`（AVL 里即 `O(log N)`）。**关键**：`sz` 必须自底向上更新；
本轮测试就抓到了「从根往下重算 sz」的写法，路径上除最底层外全部错位，
`FindKth` 随之后移（已在 `bst.c` 中改为递归回溯时更新）。

### 4.45　线索二叉树

右线索指向**中序后继**。插入一个叶子：

* 作左儿子插入 → 它的后继是父结点；
* 作右儿子插入 → 继承父结点的线索（父的后继就是它的后继），
  并把父结点的右指针改为真孩子（清除 `right_thread`）。

于是中序遍历**不用栈、不用递归**：先走到最左，然后
「有右孩子就进右子树再走到最左，否则顺着右线索走」。
删除本实现采用「标准 BST 删除 + 完整重穿线」（O(N)），
局部 O(1)/O(log N) 的改线需要分类讨论 4 种情形，取舍见文件头注释。

## 三、本轮修复的 5 个真实 bug（第 4 章）

第 4 章代码第一次跑测试时**两次卡死**、并伴随大量失败，根因如下：

1. **`avl_height_bits` 死循环（第一次卡死）**
   `avl_min_nodes` 在 10⁹ 处**饱和**，而 `avl_height_bits` 的循环条件是
   `while (avl_min_nodes(h+1) <= n) ++h;`；当 `n = 10⁹` 时
   `avl_min_nodes` 恒返回 10⁹，条件永远成立，`h` 无限增大，
   每轮还要把循环跑到 h。修法：饱和值取 `INT_MAX`（严格大于任何传入的 n）。
2. **线索树遍历死循环（第二次卡死）**
   `rethread` 只改写线索指针、从不维护 `right_thread` 标志；删除后
   出现「`right_thread = 0` 但 `right` 已是指回祖先的线索」，
   遍历时把祖先当孩子反复下行。修法：用真实结构做一次完整重穿线，
   并同步标志。顺带发现删除两孩子时 `sp->left = s->right` 会把
   **线索指针写进左孩子槽**（后继 `s` 无右孩子时），已改为置 `NULL`。
3. **B 树删除：内部结点分界键的前驱/后继取错**
   原写法取 `left->key[left->n − 1]`，但当左孩子是**内部结点**时，
   那只是它自己的最后一个键，不是整棵左子树的最大值 → 子树的键
   跑到了分界键的错误一侧。修法：一路走到最右叶子取前驱。
4. **B 树删除：对奇数 M 的“下降前预防式合并”会超容**
   在结点还有 `min_keys` 个键时就预先合并，结果是 `2·min_keys+1` 个键；
   对 M = 3,5,7 超过 `M−1`，直接写坏 `key/child` 数组（堆越界 + 段错误）。
   修法：改为**下降后**在真正下溢（`< min_keys`）时再借/合并，
   此时合并结果 `2·min_keys ≤ M−1`，永不超容。
5. **2-d 树范围查找漏掉边界点**
   该维相等的点统一放在右子树，因此右子树的关键字范围是 `≥ v`；
   剪枝条件必须是 `hi >= v`，原来写的 `hi > v` 把「正好等于右边界」
   的点全部漏掉。

另外修正了两处**测试自身的错误期望**（把 13 当成 14 的另一个叶子、
理想平衡树 IPL 公式写错）和一处恒为假的断言。
